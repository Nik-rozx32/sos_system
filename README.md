# 🆘 SOS Emergency Safety System

A Flutter-based emergency safety application designed to help users quickly send SOS alerts and share their location with trusted contacts.

## ✨ Features

- 🆘 One-tap SOS emergency alert
- 📍 Location tracking and Google Maps integration
- 👥 Emergency contact management
- 🔐 Firebase authentication
- 🔔 Push and local notifications
- 📳 Vibration feedback

## 🛠️ Tech Stack

- Flutter & Dart
- Firebase Authentication & Firestore
- Google Maps
- Geolocator
- Local Notifications
